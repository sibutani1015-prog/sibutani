# 그리드 데스크 — 데스크톱 위젯 (Electron)

`griddesk.html`(claude.ai 아티팩트) 버전과 화면·기능은 거의 같지만, 이건 **진짜 설치되는 윈도우 프로그램**이에요. 그래서 아티팩트로는 불가능했던 것들이 됩니다.

- **바탕화면 위젯 모드**: 카드가 있는 곳만 위젯이고, 빈 곳은 그 아래 바탕화면 아이콘이 그대로 클릭돼요.
- **트레이 아이콘**: 화면 오른쪽 아래에서 새로고침 · 앞으로 보기 · 모니터 선택 · 항상 맨 위 고정 · 시작 시 자동 실행 · 종료.
- **`Ctrl+Alt+D`**: 위젯을 잠깐 앞으로 가져오기.
- **윈도우 시작 시 자동 실행**: 트레이 메뉴에서 체크 한 번으로 켜고 끌 수 있어요(바로가기 파일 필요 없음).
- **진짜 파일로 저장**: 일정·메모·자료함·연락처·D-Day가 이 컴퓨터의 실제 파일(`griddesk-store.json`)에 저장돼요.

## 아직 안 되는 것

- **AI 도우미**는 이 버전에서는 꺼져 있어요. 아티팩트(웹) 버전의 AI 기능은 claude.ai가 제공하는 특수 연결(여러분의 Claude 계정을 API 키 없이 그대로 쓰는 방식)을 쓰는데, 이건 claude.ai 밖의 독립 프로그램에서는 쓸 수 없어요. 나중에 정말 필요하면 Anthropic API 키를 입력받아 붙이는 방식으로 추가할 수 있어요(그러면 실제 사용량만큼 비용이 발생해요).

## 실행해보기 (개발 중 미리보기)

Node.js가 설치되어 있어야 해요 ([nodejs.org](https://nodejs.org)에서 LTS 버전 받으면 돼요).

```bash
cd electron-widget
npm install
npm start
```

## 설치 파일(.exe)로 만들기

```bash
npm run dist
```

`dist/` 폴더에 설치 파일이 생겨요. 그 파일을 실행하면 평소 쓰던 프로그램처럼 설치되고, 시작 메뉴에 "그리드 데스크"가 생겨요.

> 참고: `npm run dist`는 Windows용 빌드를 만드는데, Mac이나 Linux에서 실행하면 추가 설정이 필요할 수 있어요. 가장 확실한 건 Windows 컴퓨터에서 직접 `npm install && npm run dist`를 실행하는 거예요.

## 파일 구성

```
electron-widget/
  main.js           앱의 메인 프로세스 — 창 생성, 클릭 통과 처리, 트레이 메뉴, 파일 저장
  preload.js        화면(HTML)이 안전하게 main.js 기능을 쓸 수 있게 연결해주는 다리
  renderer/index.html   실제 위젯 화면 (달력·일정·메모 등)
  assets/           아이콘
  package.json      빌드 설정
```

## 데이터는 어디에 저장되나요

`%APPDATA%\griddesk-widget\griddesk-store.json` (윈도우 기준)에 저장돼요. 독 안의 "퇴사 체크리스트" → 전체 내보내기로 이 내용을 다른 파일로 복사해둘 수 있고, 전체 삭제로 이 컴퓨터에서 깨끗이 지울 수 있어요.
